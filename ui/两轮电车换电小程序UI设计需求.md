# 两轮电车换电小程序 UI 设计需求

## 1. 项目概述

设计一套面向两轮电动车用户的微信小程序 UI 视觉稿，产品暂定名为 **「满电行」**。核心定位是“附近换电 + 电池租赁 + 电池暂存 + 订单管理 + 维修报修”的城市两轮车能源服务平台。

本需求只包含 **用户端 UI 视觉设计**，不涉及接口、数据逻辑、后台管理端或真实交互实现。

---

## 2. 设计目标

- 让用户快速知道附近是否有可用满电电池。
- 缓解用户的续航焦虑、找站焦虑和费用焦虑。
- 强化“安全、可信、便捷、有温度”的品牌感受。
- 适合通勤用户、外卖骑手、跑腿骑手及短途出行用户。
- 页面信息层级清晰，重点操作可单手完成。

---

## 3. 视觉方向

### 3.1 品牌气质

- 关键词：**满电、可靠、清爽、城市出行、轻科技、安心**。
- 避免过度赛博、工业风、复杂金属质感。
- 以自然绿色表达清洁能源与可靠服务，配合大面积留白和柔和圆角。

### 3.2 色彩规范

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 品牌主色 | `#16B887` | 主要按钮、选中态、可用状态、重点数据 |
| 深绿色 | `#0D4438` | 顶部深色模块、会员卡、重要标题 |
| 浅薄荷绿 | `#E7F8F1` | 背景色、提示卡、信息高亮区域 |
| 页面背景 | `#F6F8F7` | 页面大背景 |
| 卡片白色 | `#FFFFFF` | 信息卡、表单、列表容器 |
| 主文字 | `#172622` | 标题与关键数值 |
| 次级文字 | `#6F7D78` | 说明、时间、辅助信息 |
| 可用状态 | `#16B887` | 满电、正常、成功 |
| 警示色 | `#F59B45` | 库存紧张、即将到期 |
| 错误色 | `#E65B57` | 异常、报修、失败 |

### 3.3 字体与排版

- 中文字体优先使用：PingFang SC / 思源黑体 / HarmonyOS Sans SC。
- 标题使用中粗字重，正文使用常规字重。
- 以 8pt 间距体系组织页面，卡片圆角建议为 16–24px。
- 数据类信息使用更大字号和较高对比度，重点操作使用整宽主按钮。
- 图标使用统一的线性圆角图标风格，不使用表情符号作为功能图标。

### 3.4 设备画布

- 设计画布：iPhone 15 / 微信小程序用户端。
- 推荐视觉稿尺寸：`1170 × 2532 px`（3 倍图）。
- 页面顶部预留状态栏和微信小程序胶囊区域的安全空间。
- 底部导航使用 4 个一级入口：**首页、订单、服务、我的**。

---

## 4. 通用 UI 组件

### 4.1 顶部导航

- 顶部采用白底或深绿渐变背景，根据页面信息密度切换。
- 左侧为返回按钮（非一级页面），中间为页面标题，右侧可保留帮助/客服入口。
- 首页可显示当前位置，例如“杭州 · 西湖区”。

### 4.2 状态标签

| 状态 | 样式 |
| --- | --- |
| 可换电 / 库存充足 | 绿色浅底 + 深绿色文字 |
| 库存紧张 | 橙色浅底 + 橙色文字 |
| 停止服务 / 设备异常 | 红色或灰色浅底 + 说明文字 |
| 进行中 | 薄荷绿底 + 品牌绿色文字 |

### 4.3 卡片样式

- 白色背景，圆角 20px，轻微阴影或浅灰边框。
- 卡片内部采用标题、辅助说明、关键数字、操作入口的四层信息结构。
- 关键信息卡可采用浅薄荷绿、深绿渐变或极浅灰作为底色。

### 4.4 主按钮

- 主要操作：品牌绿色实心按钮，白色文字，圆角 14–16px。
- 次要操作：白底绿色描边按钮。
- 危险/取消操作：不作为页面首要按钮，使用文字按钮或浅红描边。

## 5. 页面设计清单

## 页面 01：首页 / 附近换电站

### 页面目标

让用户在打开小程序后，立即找到“离我最近且有满电电池”的换电站。

### 核心内容

- 顶部位置栏：当前城市和当前位置，例如“杭州 · 西湖区”。
- 问候信息：`早上好，王先生`。
- 当前电池状态卡：
  - 当前电量百分比，例如 `68%`。
  - 预计续航，例如 `约 31 km`。
  - 电池状态：正常。
  - 快捷操作：`扫码换电`。
- 地图主体：
  - 浅绿色城市地图底图。
  - 多个换电站定位点。
  - 当前定位点。
  - 可用库存采用绿色点位，库存紧张采用橙色点位。
- 底部最近站点浮层卡：
  - 站点名称：`西溪银泰换电站`。
  - 距离：`350 m`。
  - 可换满电电池：`12 块`。
  - 营业状态：`24 小时营业`。
  - 操作：`去换电`。
- 快捷功能入口：`电池暂存`、`预约换电`、`上报维修`、`客服帮助`。

### 视觉重点

- 地图不需要真实地理数据，保持抽象、干净、信息清晰。
- “可换满电电池数量”和“扫码换电”是页面视觉主焦点。

---

## 页面 02：换电站详情

### 页面目标

帮助用户确认该站点是否适合前往，并完成导航或预约。

### 核心内容

- 站点名称：`西溪银泰换电站`。
- 站点标签：`24 小时`、`可换电`、`支持 48V / 60V`。
- 距离与预计到达时间：`350 m · 骑行约 2 分钟`。
- 库存数据卡：
  - 可换满电：`12`。
  - 可用空仓：`8`。
  - 设备状态：`正常`。
- 电柜示意图：使用多个格口表示可用、占用、维护状态。
- 地址与服务说明。
- 底部双操作按钮：`导航前往`、`预约保留`。

### 视觉重点

- 库存数值采用大字号。
- 电柜格口用简洁图形强化“有电可换”的感知。

---

## 页面 03：扫码换电

### 页面目标

让用户快速完成扫码换电动作。

### 核心内容

- 深色或深绿色全屏背景，突出扫码框。
- 中间为大尺寸扫描取景框，四角使用品牌绿色识别线。
- 顶部标题：`扫描换电柜二维码`。
- 说明：`将二维码放入框内，即可开始换电`。
- 底部辅助入口：`手动输入设备编号`、`换电遇到问题？`。
- 提示卡：`请先归还旧电池，再领取满电电池`。

### 视觉重点

- 扫码框是唯一强焦点。
- 暗色页面中使用绿色与白色形成高对比，传达安全和操作确定性。

---

## 页面 04：换电成功 / 电池使用中

### 页面目标

让用户确认已成功领取电池，并快速了解当前电池状态。

### 核心内容

- 成功状态图标与标题：`换电成功`。
- 主电池卡：
  - 电量：`100%`。
  - 预计续航：`约 58 km`。
  - 电池编号：`MDX-6028`。
  - 健康状态：`优秀`。
- 换电信息：站点、时间、订单号。
- 安全提示：`电池异常发热时，请停止使用并立即联系客服`。
- 底部按钮：`查看订单`、`返回首页`。

### 视觉重点

- 用带有电量条的立体化简洁电池插画作为页面主视觉。
- 成功状态要有明确的绿色视觉反馈。

---

## 页面 05：电池暂存

### 页面目标

让用户方便地将备用电池存入柜体，并了解暂存费用和期限。

### 核心内容

- 页面标题：`电池暂存`。
- 当前暂存状态卡：
  - 若无暂存：`暂无暂存电池`。
  - 主操作：`扫码存入电池`。
- 服务说明：支持跨站取电、提供电池状态保护、可按小时或按天计费。
- 费用卡：
  - `前 2 小时免费`。
  - `超出后 ¥1 / 小时`。
- 常用暂存站点列表。
- 底部帮助入口：`暂存规则`、`异常处理`。

### 视觉重点

- 使用电池放入智能柜的简约插画。
- 费用信息需要透明、易读，降低用户顾虑。

---

## 页面 06：订单列表

### 页面目标

让用户快速查看换电、租赁、暂存、维修等历史记录。

### 核心内容

- 页面标题：`我的订单`。
- 顶部筛选标签：`全部`、`换电`、`暂存`、`维修`。
- 订单卡片包含：
  - 订单类型图标。
  - 订单状态：已完成、进行中、待处理。
  - 站点/服务名称。
  - 时间。
  - 金额或使用次数。
  - 右侧箭头。
- 支持日期筛选入口。

### 示例订单

1. `换电订单 · 西溪银泰换电站 · 已完成 · 今日 09:26 · ¥8.00`
2. `电池暂存 · 翠苑换电站 · 进行中 · 昨日 18:40 · 已暂存 12 小时`
3. `维修报修 · 刹车异响 · 待处理 · 2026-07-10`

### 视觉重点

- 信息卡层级明确，状态标签醒目。
- 避免表格化，采用移动端卡片列表。

---

## 页面 07：订单详情

### 页面目标

清楚展示单笔订单的服务过程和费用明细。

### 核心内容

- 订单状态大标题：`换电已完成`。
- 金额或权益信息：`本次使用月卡权益，实付 ¥0.00`。
- 订单进度时间轴：
  - `09:24 扫码开柜`。
  - `09:25 归还旧电池`。
  - `09:26 领取满电电池`。
- 电池信息：旧电池编号、新电池编号、电量、健康状态。
- 服务站点、订单编号、支付方式。
- 底部操作：`申请售后`、`联系客服`。

### 视觉重点

- 时间轴要直观、有秩序。
- 状态与费用信息位于视觉上半部分。

---

## 页面 08：维修报修

### 页面目标

让用户以低门槛方式提交电池或车辆故障。

### 核心内容

- 页面标题：`上报维修`。
- 故障类型选择：
  - 电池无法充电。
  - 电池续航异常。
  - 换电柜无法开门。
  - 车辆无法启动。
  - 刹车 / 轮胎问题。
  - 其他问题。
- 问题描述文本框：提示用户填写故障现象。
- 图片上传区：3 个图片占位格，支持拍照或相册上传。
- 联系方式与期望处理方式：`到站检修`、`上门救援`、`客服回电`。
- 提交按钮：`提交报修申请`。

### 视觉重点

- 表单分组清晰、选择状态明显。
- 图片上传区域保持轻量、简洁、容易理解。

---

## 页面 09：会员中心 / 套餐购买

### 页面目标

展示月卡权益，促进订阅和提升用户留存。

### 核心内容

- 深绿色渐变会员头图。
- 用户身份：`普通用户` 或 `满电会员`。
- 当前权益：剩余换电次数、到期日期、累计节省金额。
- 套餐卡横向展示：
  - `轻享月卡`：每月 12 次换电。
  - `通勤月卡`：每月 30 次换电。
  - `骑手畅换卡`：高频骑行优先预约。
- 推荐套餐突出显示“推荐”。
- 权益说明：优先预约、库存提醒、道路救援折扣、暂存优惠。
- 底部按钮：`立即开通`。

### 视觉重点

- 会员区需具备高级感，但保持简洁和可信。
- 套餐价格、使用次数、推荐标签要突出。

---

## 页面 10：我的 / 个人中心

### 页面目标

作为用户账户、车辆、电池、优惠和客服服务的聚合入口。

### 核心内容

- 用户头像、昵称、手机号脱敏展示。
- 会员状态卡：`开通月卡，换电更省心`。
- 数据概览：累计换电次数、绿色骑行公里数、节省金额。
- 常用功能入口：
  - 我的电池。
  - 我的车辆。
  - 优惠券。
  - 地址与常用站点。
- 服务功能列表：
  - 维修与救援。
  - 帮助中心。
  - 在线客服。
  - 设置。

### 视觉重点

- 用户信息区要有温度和品牌认同感。
- 功能模块采用图标 + 文字 + 右箭头的轻列表形式。

---

## 6. 页面状态补充

设计时需要为关键页面预留以下状态：

- 换电站无满电电池。
- 换电柜满仓，无法归还旧电池。
- 用户定位未开启。
- 网络异常。
- 扫码失败。
- 订单进行中。
- 维修工单处理中。
- 月卡即将到期。
- 暂存时间即将超时。

状态页不需要独立复杂设计，可沿用基础页面布局，通过插画、状态文案、次级按钮和帮助入口呈现。

## 7. UI 交付要求

- 每个页面输出独立高清 PNG 视觉稿。
- 文件建议命名：
  - `01-首页-附近换电站.png`
  - `02-换电站详情.png`
  - `03-扫码换电.png`
  - `04-换电成功.png`
  - `05-电池暂存.png`
  - `06-订单列表.png`
  - `07-订单详情.png`
  - `08-维修报修.png`
  - `09-会员中心.png`
  - `10-我的.png`
- 所有页面需维持统一的颜色、字体、圆角、图标与卡片体系。
- 仅展示 UI 视觉与示例数据，不需要实现真实按钮跳转、地图定位、支付、扫码、订单接口或维修业务逻辑。
